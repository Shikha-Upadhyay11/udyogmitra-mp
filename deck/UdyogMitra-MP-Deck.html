Our Solution

One Zero-Training Voice OS. Four Connected Growth Engines.

1. Voice Copilot & OCR

Speak in Hindi/Hinglish or scan a bill → extracts Party, HSN, Qty, CGST/SGST (9%+9%), and updates stock.

2. UdyogTrust Credit

Every invoice & UPI receipt builds a live 300–900 cash-flow score for instant OCEN / SIDBI working capital.

3. ONDC B2B Store

1-click catalog & spare CNC capacity publishing to capture B2B RFQs from Bhopal, Pune & beyond.

4. MP SkillBridge

AI detects hiring gaps and matches Govt. ITI Indore/Pithampur youth into 2-week NAPS apprenticeships.

Why It's Unique: We don't build another standalone billing app. Digitizing daily MSME operations automatically fuels both formal credit eligibility and hyper-local youth employment in a single regional flywheel.

Architecture & Tech Stack

Built on Open Web + India's Digital Public Infrastructure (DPI)

Working Prototype Stack

  • Frontend: React 18, TypeScript, Vite, Tailwind CSS (bilingual EN/हिंदी UI).
  • Voice & NLP: Web Speech API (hi-IN / en-IN) + offline-resilient Hinglish MSME entity extractor.
  • GST Engine: Printable MP State-Code 23 tax invoices with HSN & CGST/SGST auto-split.
  • Deployment: Public GitHub + Vercel Edge Hosting.

DPI Integration Architecture

  • GSTN / e-Invoice: Structured GSTR-1 ready JSON export per transaction.
  • Account Aggregator & OCEN 4.0: Consent-based cash-flow sharing with SIDBI / MPFC / NBFCs.
  • ONDC B2B Protocol: Open seller node for regional manufacturing clusters.
  • Skill India / NAPS: Verifiable digital credentials & DBT stipend workflow.
